# Migration Guides

## v1 → v2 (Future)

No v2 breaking changes have been announced. This page will be updated when a new major version is planned.

## How to Prepare

1. **Follow the compatibility guidelines** in [backward-compatibility.md](backward-compatibility.md).
2. **Monitor the changelog** — [changelog.md](changelog.md) tracks all changes.
3. **Test against staging** before deploying to production.
4. **Use the TypeScript SDK** — it provides type checking and will surface breaking changes at compile time.

## Getting Help

Contact the STR Platform engineering team at `engineering@strplatform.com` for migration assistance.
