# STR Platform Frontend (Next.js)

Production-oriented Next.js app router frontend scaffold for the STR marketplace platform.

## Quick start

```bash
npm install
cp .env.local.example .env.local
npm run dev
```

## Included

- Next.js + TypeScript + Tailwind
- Role-based app route groups for auth, vendor, courier, and admin
- Shared UI components and dashboard shells
- Zustand store + React Query providers
- Axios API client and service stubs
- Socket.io hook and map/payment component placeholders
- Jest + React Testing Library setup
- Cypress E2E config scaffold
